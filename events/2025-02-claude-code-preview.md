## What Happened

Anthropic introduced Claude Code as an agentic coding tool designed to operate inside a developer’s terminal workflow, with capabilities like reading and editing code, running tests, and using CLI tools under user supervision.

## Why It Matters

Claude Code marked a clear step from chat-based “coding help” toward tool-using agents that can execute real workflows, making it a natural comparison point to OpenAI’s Codex direction.

## Technical Details

- **Workflow:** Terminal-native agentic coding (per announcement framing)
- **Release stage:** Limited research preview at launch
