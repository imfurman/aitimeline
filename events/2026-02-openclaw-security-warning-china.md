## What Happened

In February 2026, Chinese authorities publicly warned about security risks linked to OpenClaw deployments, pointing to misconfiguration and operational risks around agent platforms that can access data and execute actions.

## Why It Matters

This event underscores that agentic AI is not only a model capability story, but also an operations and security story. As agents gain deeper access to devices and services, governance and safe deployment practices become a first-order concern.

## Technical Details

The warning focused on deployment posture and controls (e.g., audits, access controls, identity verification), reflecting a broader trend: agent systems expand the attack surface beyond classic prompt injection to include configuration, extension marketplaces, and “skills” execution pathways.
