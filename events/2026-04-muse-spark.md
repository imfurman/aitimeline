## What Happened

Meta introduced Muse Spark on April 8, 2026, as the first model in the Muse family developed by Meta Superintelligence Labs. It became available that day through the Meta AI app and website, alongside a private API preview for selected users. The announcement also described a gradual rollout of Contemplating mode.

## Why It Matters

Muse Spark marked a new model generation built after an overhaul of Meta’s training stack. Its release brought multimodal reasoning and coordinated agent execution into Meta’s consumer assistant. It also highlighted parallel reasoning agents as a practical way to increase inference-time computation without simply extending one model’s response sequence.

## Technical Details

Muse Spark supports tool use, visual reasoning and multi-agent orchestration. Meta described changes across pretraining, reinforcement learning and test-time reasoning. Reinforcement learning includes penalties on thinking time to improve reasoning efficiency; Contemplating mode coordinates agents reasoning in parallel. This event records a hosted release and limited API preview, not a downloadable-weight release.
