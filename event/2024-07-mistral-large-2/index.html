Mistral Large 2

Mistral AI releases Mistral Large 2, a flagship model emphasizing long context, multilingual performance, and tool/function calling.

July 24, 2024 Model Release

What Happened

Mistral AI announced Mistral Large 2 as a new generation of its flagship model, highlighting improvements in code generation, reasoning, multilingual ability, and function calling.

Why It Matters

Mistral Large 2 helped broaden the set of credible non-US, open(-weight)/license-controlled frontier alternatives, particularly for multilingual and long-context production scenarios.

Technical Details
