GPT-5.2

OpenAI releases GPT-5.2, emphasizing stronger long-context understanding, agentic tool use, and improved real-world task execution.

December 11, 2025 Model Release

What Happened

OpenAI released GPT-5.2 as a frontier model family (Instant, Thinking, and Pro variants) for ChatGPT and for developers via the API.

Why It Matters

GPT-5.2 represents the “production frontier” pattern: pairing general capability improvements with better long-context reliability and stronger tool-calling behavior suited to end-to-end task execution.

Technical Details

  • Variants: Instant / Thinking / Pro (as described in the announcement)
  • Focus areas: Long-context understanding, tool calling, vision, and complex workflow execution
  • Availability: Announced as rolling out in ChatGPT and available in the API
