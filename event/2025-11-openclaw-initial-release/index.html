OpenClaw (initial release as Clawd/Clawdbot)

OpenClaw begins as an open-source personal AI assistant project (initially branded Clawd/Clawdbot), launching in November 2025.

November 1, 2025 Open Source

What Happened

The OpenClaw project traces its origins to November 2025, when it was first released under earlier branding (e.g., Clawd/Clawdbot). The timeline date uses 2025-11-01 to represent month-level granularity where sources specify the month rather than a precise day.

Why It Matters

OpenClaw represents a shift from single-session chatbots to agent platforms that run “close to the user,” integrate with existing chat channels, and can execute multi-step tasks with local access—raising both productivity opportunities and security concerns.

Technical Details

OpenClaw is positioned as a personal assistant you run on your own devices, typically integrating with multiple messaging platforms and supporting extensible “skills” or connectors.
