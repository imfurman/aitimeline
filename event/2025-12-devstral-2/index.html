Devstral 2

Mistral releases Devstral 2, a frontier coding model designed for agentic workflows over real codebases.

December 9, 2025 Model Release

What Happened

Mistral announced Devstral 2 as a coding-focused model intended to support agentic workflows such as exploring codebases, orchestrating multi-file changes, and iterating on failures.

Why It Matters

Devstral illustrates how “agentic coding” quickly became its own model category: models are optimized for tool use, repo-scale context, and multi-step reliability, not only code snippet generation.

Technical Details

  • Target workflows: Repo navigation, multi-file edits, tool-augmented debugging
