GPT-5.4

OpenAI releases GPT-5.4, combining general reasoning, coding, and native computer use in one model.

March 5, 2026 Model Release

What Happened

On 2026-03-05, OpenAI released GPT-5.4 in the API and began rolling it out in ChatGPT and Codex, alongside GPT-5.4 Pro.

Why It Matters

It consolidated specialized coding capabilities and native computer interaction into a mainline general-purpose reasoning model. This reduced the separation between asking a model to reason, delegating software changes, and having an agent operate an application. A shared model could support these activities across the same extended task and context.

Technical Details

OpenAI described GPT-5.4 as its first general-purpose model with native computer use. The API and Codex supported up to one million context tokens, with experimental configuration in Codex. Tool search let agents discover relevant tools without loading every definition into context.
